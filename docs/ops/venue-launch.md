# Запуск в зале «Друзья»

Чеклист до первого гостя и сухой прогон. Код уже умеет бонусы, кассу, check-in и игры — без контента и тренировки мастеров бот «пустой».

## Что заполнить в веб-админе

Откройте бота с аккаунта `TELEGRAM_ADMIN_ID` → «Веб-админ» (не из обычного Chrome).

1. **Контакты** и **Как доехать** — адрес, часы, ссылка на карту.
2. **Меню** — 8–15 позиций с фото (лучше S3, иначе файлы живут в volume `uploads`).
3. **Настройки:** процент с чека, бонус регистрации, бонус ДР, длина визита, TTL бонусов, таблица призов недели.
4. **Бренд** — логотип и цвета, если хотите не дефолт.
5. **Роли** — Telegram ID мастеров.
6. **График смен** — иначе уведомления о check-in уходят всем мастерам/админам.

Правила турнира: призы за **общий зачёт** по сумме игр, не «победитель каждой игры». Так и говорите гостям.

## Скрипт мастера (одна страница)

- На стойке всегда виден **код зала** (QR + PIN). Ротация каждые 2 часа — сразу обновить планшет или распечатку.
- Гость без check-in не играет в зачёт. Не диктуйте чужой PIN — только код зала.
- «Найти гостя» → телефон, QR гостя или имя → **Чек** (сумма в рублях). Процент считает бот.
- Списание бонусов — только если гость просит. Крупные списания — старший смены.
- Не открывайте веб-админ с гостевого телефона.

Кнопка «Игры» в меню чата иногда требует второй тап (ограничение Telegram). Можно жать кнопку меню бота «Игры».

## Сухой прогон (вечер до открытия)

Два телефона: гость и мастер, плюс админ.

1. `/start` → регистрация → бонус за регистрацию → QR гостя.
2. Мастер показывает код зала → гость check-in PIN и QR → визит открыт.
3. Гость играет одну партию → очки в рейтинге.
4. Мастер: поиск по имени, чек 2000 ₽ → бонус 10%, продлить визит, списать 50, погасить тестовый купон.
5. Админ: рассылка сегменту «все» на тестовые id; статистика за сегодня.
6. Гость: бронь на завтра → уведомление мастеру → подтвердить.
7. Реферал: второй аккаунт по ссылке «Пригласить друга» → check-in → бонусы обоим.
8. `docker compose restart app` → `/health/ready` отвечает `{"ok":true}`, webhook жив, код зала можно заново показать.

Мониторинг: внешний ping `https://домен/health/ready`. Бэкап: `./scripts/backup-postgres.sh`.
