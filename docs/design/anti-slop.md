# Anti-slop: как делать сайты клиентам, чтобы они не выглядели «сделанными нейронкой»

> Для кого: агенты Cursor и люди, которые делают сайты/лендинги для локального бизнеса (барбершопы, салоны, тату-студии, автосервисы, фитнес, небольшие локальные компании в России).
> Откуда это взялось: реальный отзыв потенциального клиента — «нейрослоп: плашки, текст, шрифт банальный, не отличается от того, что обычно делают нейронки».

## 0. Главная мысль

Нейросеть по умолчанию выдаёт **статистическое среднее** «современного сайта»: Inter, фиолетово-синий градиент, центрированный hero, три одинаковые карточки с иконками, `rounded-2xl` и мягкие тени везде. Каждый такой выбор по отдельности нормальный, но 4–5 вместе — и любой дизайнер узнаёт шаблон за секунду. Поменять цвет градиента с фиолетового на зелёный не поможет: проблема в том, что **решения никто не принимал**.

Цель: каждый сайт должен выглядеть так, будто **человек-дизайнер придумал отдельный стиль именно для этого бизнеса** — его места, вывески, района, мастеров, клиентов. Если сайт можно перенести на другой барбершоп, поменяв логотип, — это провал.

Порядок работы всегда такой:

1. **Арт-дирекшн (до кода!)** → `docs/design/concept.md` (раздел 2).
2. Обязательные решения: шрифты, сетка, сигнатурный приём, палитра, фото (раздел 3).
3. Вёрстка с учётом запретов (раздел 1).
4. Проверка перед сдачей (раздел 7).

## 1. Запрещённые паттерны (чек-лист)

Если на странице есть **3 и больше** пунктов из списка — переделывать. Отдельный пункт допустим, только если он прямо обоснован в `concept.md` (например, фиолетовый — реальный фирменный цвет клиента).

### Типографика
- [ ] Основной шрифт — Inter, Roboto, Open Sans, Montserrat, Poppins, Nunito, Raleway, Manrope, Geist, Comfortaa, Lobster, Oswald, Playfair Display (это «шрифты по умолчанию» нейронок и шаблонов Tilda/Taplink).
- [ ] Шрифт без кириллицы (Poppins, Bebas Neue, Space Grotesk, Syne, Fraunces, Instrument Serif, DM Serif Display, Bricolage Grotesque…) — кириллица падает в системный fallback, и это сразу видно.
- [ ] Один шрифт на всё, заголовки `font-bold tracking-tight` размером 48–60px, текст 16px — нет контраста масштаба.
- [ ] Весь текст выровнен по центру, включая абзацы.
- [ ] Чистый `#000` / `#fff` для текста и фона.

### Цвет и поверхности
- [ ] Фиолетово-синие/индиго градиенты (Tailwind `blue-600 → indigo-700`, `violet-500`), «свечение», градиентный текст.
- [ ] Glassmorphism: полупрозрачные карточки с `backdrop-blur`, тонкой рамкой и тенью на тёмном/градиентном фоне.
- [ ] Одинаковый радиус (16px / `rounded-2xl`) и одинаковая мягкая тень у всех элементов.
- [ ] Палитра «придумана» — не взята из реального бренда/места клиента.
- [ ] Тёмная тема «потому что стильно», без связи с местом.

### Композиция
- [ ] Hero: по центру заголовок «X — это Y», подзаголовок и две кнопки («Записаться» + «Узнать больше»).
- [ ] **Плашки**: 3 (или 4, 6) одинаковые скруглённые карточки в сетке, в каждой иконка в цветном кружке + заголовок + 2 строки текста.
- [ ] Иконки Lucide/Heroicons в тонированных кругах, галочки в кружках в списках.
- [ ] Эмодзи вместо маркеров (✂️ 💈 🔥 ✨ ✅) и эмодзи в заголовках.
- [ ] Всё в `max-w-7xl mx-auto`, все секции одинаковой высоты и с одинаковыми отступами, строго симметрично.
- [ ] Стандартный порядок блоков: Hero → Преимущества → Услуги → Отзывы (5 звёзд, аватарки-заглушки) → FAQ-аккордеон → CTA → футер.
- [ ] Цифры-счётчики «500+ довольных клиентов / 10 лет опыта / 24/7».
- [ ] Бейдж «Популярное» с градиентом на средней карточке тарифа.

### Изображения
- [ ] Стоковые/AI-фото: идеальные улыбающиеся люди, «барбер с ножницами на чёрном фоне», нереалистичные интерьеры, 6 пальцев.
- [ ] Абстрактные 3D-блобы, сферы, «аврора», шумовые градиенты как замена фото.
- [ ] Аватарки DiceBear/инициалы в кружках в отзывах.

### Текст
- [ ] Пустой копирайт: «Мы ценим каждого клиента», «Индивидуальный подход», «Команда профессионалов», «Качество и надёжность», «Ваш комфорт — наш приоритет», «Откройте для себя мир…», «Погрузитесь в атмосферу…».
- [ ] Шаблонные заголовки секций: «Почему выбирают нас», «Наши преимущества», «Наши услуги», «Что говорят клиенты».
- [ ] Тройки прилагательных («стильно, быстро, качественно»), тире-конструкции, одинаковая длина всех пунктов.
- [ ] Нет ни одного конкретного факта: адреса с ориентиром, имени мастера, цены, часов работы, названия улицы/района.

## 2. Обязательный шаг: арт-дирекшн ДО кода → `docs/design/concept.md`

Ни одной строки вёрстки, пока не написан `docs/design/concept.md` для этого сайта (в репозитории с несколькими сайтами — `<папка-сайта>/docs/design/concept.md`). Это короткий документ (0.5–1 страница), а не формальность: по нему ревьюер проверяет, что стиль придуман, а не сгенерирован.

### Шаблон `concept.md`

```markdown
# Концепт: <название бизнеса>, <город>

## 1. Кто клиент
Что за место, кто владелец/мастера, кто приходит (возраст, район, повод), чем отличаются от соседей.
Факты из брифа, 2ГИС/Яндекс Карт, соцсетей, фото — не выдумывать.

## 2. Метафора / настроение
Одна фраза, взятая из реального места: материалы, вывеска, район, эпоха здания, интерьер.
Пример: «Парикмахерская в сталинке на Ленина: латунь, кафель 60-х, рукописный прайс на стене».

## 3. Неожиданная, но обоснованная идея (ровно одна, сигнатурная)
Например: типографика по мотивам старой вывески; прайс как кассовый чек; расписание как афиша;
портфолио как флеш-лист; услуги как заказ-наряд автосервиса; навигация как номерки гардероба.
Почему это про ЭТОТ бизнес (1–2 предложения).

## 4. Типографика
Акцидентный шрифт + текстовый (+ опционально моно). Почему они (связь с метафорой). Шкала размеров (минимум 1:4 между текстом и главным заголовком).

## 5. Сетка
Концепт сетки (редакционная асимметрия / узкая колонка / сетка техкарты / плакат…), ломаем её осознанно где: …

## 6. Палитра
Из реального бренда/места: логотип, вывеска, стены, форма мастеров. 1 основной + 1 акцент + 2 нейтральных (тёплые/холодные «почти чёрный» и «почти белый»). HEX и откуда взят каждый цвет.

## 7. Фото
Что есть реального, что нужно доснять/попросить, как обрабатываем (цвет, кадрирование, зерно). Чего не используем.

## 8. Намеренные несовершенства и асимметрия
2–4 конкретных приёма: смещённый заголовок, выходящая за край фотография, рукописная пометка мастера,
неровная обрезка, «штамп», несимметричные отступы, разный ритм секций. Где именно.

## 9. Голос
3–5 фраз так, как говорит сам владелец/мастер (из соцсетей, переписки, отзывов). Слова, которые не используем.

## 10. Пресет-отправная точка (если есть) и что изменено
Название пресета из anti-slop.md + минимум 3 изменения под этого клиента.
```

### Правила концепта
- **Уникальность.** У каждого сайта свой концепт. Пресет из раздела 6 — только отправная точка; использовать его без изменений запрещено (минимум 3 содержательных отличия: метафора, сигнатурный приём, палитра из бренда, шрифтовая пара).
- **Источник — реальность.** Метафора и палитра берутся из реального места: вывеска, фасад, интерьер, район, эпоха здания, униформа, инструменты, история владельца. Нет данных — спросить/посмотреть фото в 2ГИС и соцсетях, а не придумывать «премиальный лофт».
- **Одна сильная идея**, а не пять средних. Сигнатурный приём должен быть виден в hero и повторяться ещё минимум в 2 местах.
- **Несовершенство — запланированное.** Асимметрия и «ручные» детали описываются заранее, а не появляются из-за кривой вёрстки. Доступность и читаемость не жертвуем.

## 3. Обязательные решения на каждый сайт

| Решение | Требование |
|---|---|
| Шрифтовая пара | Акцидентный шрифт с характером + читаемый текстовый. Оба с кириллицей. Из списка в разделе 4 или обоснованная замена. Контраст масштаба: H1 ≥ 4× размера основного текста, на десктопе часто 96–180px. |
| Концепт сетки | Названный и описанный: редакционная асимметрия, узкая колонка + поля, плакат, техкарта, флеш-лист, чек и т.д. Минимум одно осознанное нарушение сетки на экран. |
| Сигнатурный приём | Один визуальный ход, по которому сайт запоминается и который нельзя перенести на соседа. |
| Палитра | Из реального бренда/места. Максимум 1 яркий акцент. Тёплые/холодные нейтральные вместо `#000/#fff`. |
| Фото | Реальные фото клиента (интерьер, мастера, работы, фасад, вывеска). Обработка единая. Стоки/AI — только как временная заглушка с пометкой `TODO: заменить на фото клиента`. |
| Радиусы и тени | Выбраны под концепт: 0px (плакат, техкарта), 2–4px (печать), или «таблетки» осознанно. Не один `16px` на всё. Тени — редко и по смыслу (бумага, наклейка), не по умолчанию. |
| Текст | Голос владельца, конкретика: адрес с ориентиром («вход со двора, за «Магнитом»»), имена мастеров, цены «от», время, парковка, как записаться. |

### Чем заменять «плашки»
- Список услуг с ценами в виде **прайса/меню** (точечные лидеры, моноширинные цифры, `font-variant-numeric: tabular-nums`).
- **Нумерованные** пункты крупными цифрами (01, 02…) без рамок, в 1–2 колонки с разной шириной.
- Таблица / техкарта / афиша / чек — в зависимости от концепта.
- Фото + подпись в стиле журнала вместо иконки.
- Если карточки необходимы — разного размера и наполнения (бенто осознанно, не 3×одинаковые), без иконок в кружках.

### Hero без шаблона
- Не «X — это Y» + 2 кнопки по центру. Варианты: огромное название/адрес как вывеска; фото мастера на весь экран с подписью; первый экран = прайс/расписание; одна фраза владельца; цитата клиента из реального отзыва.
- Одна главная кнопка записи (в голосе бизнеса: «Записаться к Саше», «Свободные окна на неделю»), вторичная — текстовая ссылка (телефон, Telegram, адрес).

## 5. Что делают живые дизайнеры (принципы)

1. **Контраст масштаба.** Огромный заголовок рядом с мелким текстом и подписями. Разные размеры секций.
2. **Редакционная/асимметричная сетка.** 12 колонок, но контент занимает 5+7, 3+9, 2+6+4; поля и воздух — элемент композиции.
3. **Одна идея на сайт.** Сигнатурный приём проходит через весь сайт.
4. **Реальные фото** с единой обработкой, смелое кадрирование (крупно руки, инструмент, фактура), фото «в край».
5. **Сдержанная палитра из бренда** — 1 акцент. Цвет вывески, плитки, униформы.
6. **Детали бренда:** номер дома, год основания, фрагменты вывески, режим работы как табличка на двери, схема прохода.
7. **Голос клиента:** микрокопи так, как говорит владелец («Стрижём с 2016-го. Без записи — если повезёт»).
8. **Локальная специфика:** район, ориентиры, парковка, остановка, «вход со двора», ссылки на 2ГИС/Яндекс Карты, Telegram/VK, а не Instagram-иконки по умолчанию.
9. **Намеренное несовершенство:** штамп, рукописная пометка, обрезанное слово, наложение текста на фото, смещённая колонка.

## 6. Пресеты арт-дирекшна (только отправные точки!)

> Пресет нельзя применять без изменений. В `concept.md` указывается, от какого пресета оттолкнулись и что минимум трижды изменено под клиента. Референсы — для настроения и принципов, не для копирования.

### П1. «Вывеска»
- **Настроение:** старая городская вывеска, эмаль, объёмные буквы, номер дома. Честно, громко, локально.
- **Шрифты:** Sofia Sans Extra Condensed (капс, плотный трекинг) + PT Serif; цифры адреса — гигантские.
- **Палитра:** цвет реальной вывески/фасада (эмалевый красный, бутылочно-зелёный, синий) + «бумага» (`#f2ede4`) + почти чёрный (`#1b1a17`).
- **Сетка:** узкие высокие колонки; заголовок пересекает колонки и фото.
- **Сигнатура:** название/адрес набраны как буквы вывески (можно с лёгкой «неоновой» или металлической обводкой), режим работы — как табличка на двери.
- **Ниши:** барбершоп, мастерская, кофейня.
- **Референсы:** murdocklondon.com, blindbarber.com; галереи siteinspire.com, minimal.gallery.

### П2. «Чек / прайс»
- **Настроение:** кассовый чек, рукописный прайс на стене, тикет электронной очереди.
- **Шрифты:** JetBrains Mono или Martian Mono (прайс, цифры) + Alumni Sans / Sofia Sans Extra Condensed (заголовки).
- **Палитра:** термобумага (`#f7f5ef`), чёрный, один цвет «штампа» (синий/красный).
- **Сетка:** одна узкая колонка «ленты» по центру + широкие поля с фото, которые выходят за край.
- **Сигнатура:** услуги и цены как чек с точечными лидерами, перфорацией, «ИТОГО», QR на запись; номер «талона» как элемент навигации.
- **Ниши:** барбершоп, автосервис, шиномонтаж, химчистка.
- **Референсы:** brutalistwebsites.com (принципы честной сетки).

### П3. «Журнал»
- **Настроение:** глянцевый/независимый журнал о красоте; разворот, подписи, буквицы.
- **Шрифты:** Cormorant Garamond (крупно, курсив в акцентах) + Ysabeau или Tenor Sans.
- **Палитра:** из интерьера салона (пудровый, оливковый, терракота) + тёплый белый + графит.
- **Сетка:** асимметричная 12-колоночная, фото «в край», текст колонками 5/7, подписи к фото мелким кеглем.
- **Сигнатура:** мастера — как герои журнальных материалов (интервью-цитата, фото рук за работой); номер «выпуска» = сезонное предложение.
- **Ниши:** салон красоты, косметология, ногти, спа.
- **Референсы:** aesop.com, lelabofragrances.com, kinfolk.com.

### П4. «Флеш-лист»
- **Настроение:** стена тату-салона с флешами, бумага, тушь, трафареты.
- **Шрифты:** Dela Gothic One или Ruslan Display (заголовки) + IBM Plex Mono / PT Serif.
- **Палитра:** бумага + тушь (почти чёрный) + один «тату»-цвет (красный/зелёный из реальных работ).
- **Сетка:** лист флешей: работы плотной сеткой разного размера с номерами, рамками от руки.
- **Сигнатура:** портфолио как флеш-лист с номерами («№ 14 — свободен»), запись как «бронь эскиза».
- **Ниши:** тату, пирсинг, барбер с характером.
- **Референсы:** bangbangforever.com.

### П5. «Техкарта / заказ-наряд»
- **Настроение:** гараж, чертёж, заказ-наряд, коды деталей, бетон и сигнальная разметка.
- **Шрифты:** Tektur или Russo One + IBM Plex Sans / IBM Plex Mono.
- **Палитра:** бетон/графит, сигнальный жёлтый/оранжевый — только если есть в реальной вывеске/форме; иначе цвет бренда клиента.
- **Сетка:** миллиметровка/чертёжная сетка, размерные линии, выноски на фото машины.
- **Сигнатура:** услуги как строки заказ-наряда (код, работа, норма-часы, цена от), этапы ремонта как техпроцесс.
- **Ниши:** автосервис, детейлинг, шиномонтаж, ремонт техники.
- **Референсы:** singervehicledesign.com (подача ремесла и деталей).

### П6. «Афиша / плакат»
- **Настроение:** конструктивистский/спортивный плакат, расписание на стене зала.
- **Шрифты:** Alumni Sans Black или Dela Gothic One + Onest / Golos Text.
- **Палитра:** два цвета + чёрный (из формы/логотипа зала), без градиентов.
- **Сетка:** диагонали, огромные цифры, наложение типографики на фото; радиус 0.
- **Сигнатура:** расписание тренировок как афиша (дни крупно, тренеры как «участники»), цены абонементов как билеты.
- **Ниши:** фитнес, бокс, танцы, йога-студия с характером.
- **Референсы:** equinox.com (фото и типографика), brutalistwebsites.com.

### П7. «Ремесло / тёплый дом»
- **Настроение:** маленькая мастерская, натуральные материалы, рукописные заметки мастера.
- **Шрифты:** Alegreya + Alegreya Sans (или Literata + Golos Text), Caveat — 1–2 пометки.
- **Палитра:** из материалов интерьера: дерево, лён, глина, зелень; без «чистых» цветов.
- **Сетка:** спокойная, с широкими полями; фото фактур крупно; блоки разной ширины.
- **Сигнатура:** пометки мастера от руки на фото («тут у нас кофе»), карта проезда нарисованная, а не iframe по умолчанию.
- **Ниши:** массаж, ногтевая студия на дому, пекарня, флорист, локальная мастерская.
- **Референсы:** kinfolk.com, aesop.com.

### П8. «Галерея / тишина»
- **Настроение:** премиальная тишина, много воздуха, одна фотография на экран.
- **Шрифты:** Prata или Forum + Golos Text; номера разделов моноширинным.
- **Палитра:** монохром из бренда (один глубокий цвет + тёплый белый), без акцентов-кнопок «кислотного» цвета.
- **Сетка:** крупные фото, текст мелкими блоками по краям, нумерованная навигация (I, II, III).
- **Сигнатура:** каждая услуга — «экспонат» с подписью как в музее (название, мастер, длительность, цена).
- **Ниши:** премиум-салон, клиника эстетики, барбер premium.
- **Референсы:** byredo.com, lelabofragrances.com, minimal.gallery.

## 7. Проверка перед сдачей: «узнает ли дизайнер нейронку?»

Пройти **на скриншотах** (десктоп 1440 и мобильный 390), а не по коду.

**Концепт**
- [ ] `docs/design/concept.md` существует, написан до вёрстки, содержит метафору из реального места, одну сигнатурную идею, несовершенства и источник каждого цвета.
- [ ] Если взят пресет — в концепте перечислены ≥3 изменения; сайт не похож на другой сайт из этого репозитория.
- [ ] Тест «замени логотип»: если подставить другой барбершоп — сайт перестанет работать? Должен перестать.

**Визуал**
- [ ] Ни одного пункта-«убийцы» из раздела 1 без обоснования; суммарно < 3.
- [ ] Шрифты из раздела 4 (или обоснованная замена), кириллица без fallback-глифов (проверить «Ёё Йй Щщ Ъъ ₽ №»).
- [ ] Есть контраст масштаба; H1 не 48px `font-bold` по центру.
- [ ] Сигнатурный приём виден в первом экране и повторяется минимум ещё в 2 местах.
- [ ] Есть осознанная асимметрия и хотя бы 2 «ручные» детали из концепта.
- [ ] Нет одинаковых карточек с иконками в кружках; нет эмодзи-буллетов; нет glassmorphism и фиолетовых градиентов.
- [ ] Радиусы/тени соответствуют концепту, а не дефолту.
- [ ] Фото реальные (или помечены TODO на замену), обработка единая.

**Текст**
- [ ] Нет фраз из стоп-листа («ценим каждого клиента», «индивидуальный подход», «команда профессионалов», «почему выбирают нас»…).
- [ ] Есть конкретика: адрес с ориентиром, имена мастеров, цены, часы, способ записи (YCLIENTS/Telegram/телефон).
- [ ] Микрокопи звучит как владелец, а не как маркетолог.

**Финальный вопрос:** покажи скриншот человеку, который не знает, кто делал сайт. Если первая реакция — «шаблон/нейронка» — не сдавать.
